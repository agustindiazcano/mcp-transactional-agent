# System Telemetry & Performance Testing

To ensure the Agentic MCP Engine is truly enterprise-grade, we rely on empirical metrics rather than assumptions. This document details the specific telemetry, load testing, and coverage tracking methodologies implemented in the project.

## 1. Test Coverage (Code Quality)
A high test coverage percentage (targeting 80%+) ensures that the core transactional logic is actively executed and validated by our test suites, preventing regressions during refactors.

- **Tooling:** `pytest-cov`
- **Execution:** We generate a detailed missing-line report to explicitly identify which edge cases or error-handling blocks remain untested.
- **Command:**
  ```bash
  pytest --cov=src tests/ --cov-report=term-missing
  ```

## 2. Load Testing (Latency & Throughput)
To validate the system's resilience under heavy concurrency, we must measure its real throughput and latency limits.

- **Tooling:** `locust`
- **Mechanism:** The load test script (`tests/performance/locustfile.py`) simulates a massive swarm of concurrent users. Each user fires HTTP POST requests to the `/api/v1/claims` ingestion endpoint, attaching unique `request_id`s to simulate high-volume transaction bursts without triggering idempotency locks.
- **Key Metrics Tracked:**
  - **RPS (Requests Per Second):** The system's ingestion throughput (FastAPI -> RabbitMQ).
  - **P95 Latency:** The response time under which 95% of the requests are successfully accepted (HTTP 202).
- **Command:**
  ```bash
  locust -f tests/performance/locustfile.py --headless -u 100 -r 10 --run-time 1m --host http://localhost:8000
  ```

## 3. LLM Observability & Cost Tracking
Because the LLM inferences represent the primary operational cost and volatility factor, they are strictly monitored at runtime.

- **Tooling:** `Langfuse`
- **Mechanism:** The `langfuse` callback handler is injected into all LLM calls (both the Primary Agent and the deterministic LLM-Judge guardrail).
- **Key Metrics Tracked:**
  - Token consumption (Prompt vs. Completion tokens).
  - Estimated cost per transaction.
  - Generative latency (E2E Agentic Processing Time).
  - Tool execution trace isolation.
